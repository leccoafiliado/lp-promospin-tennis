# PromoSpin — Landing Page

Landing page do grupo de ofertas **PromoSpin Tennis** (convite para o grupo do WhatsApp).

Página única e autossuficiente (`index.html`): logo embutido, fontes via Google Fonts,
Meta Pixel e Microsoft Clarity (heatmap) já integrados.

## Recursos
- Hero com CTA para o grupo do WhatsApp
- Barra fixa com contador regressivo (urgência)
- Popup de prova social (números de WhatsApp aleatórios com DDDs do Brasil)
- Rastreamento: Meta Pixel + Microsoft Clarity

## Uso
Basta abrir ou hospedar o `index.html` — não precisa de build nem dependências.
